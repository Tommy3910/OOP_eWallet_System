# OOP_eWallet_System
this is a e-wallet system for oop 
The system can store multiple payment accounts, such as:

Bank Debit Account
TouchNGo Account

Each account should be able to:

store account number
store balance
top up balance
make payment
check balance

The user should be able to:

add account
view accounts
top up account
make payment
quit program

The program repeats until the user quits.
